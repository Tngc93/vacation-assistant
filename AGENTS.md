# AGENTS.md — Vacation Assistant

Vacation Assistant, Türkiye'den (İstanbul ya da Ankara) yurt dışına kısa şehir tatili planlayan gezginler için açık kaynak bir web uygulamasıdır. Tek ekranda en ucuz uçuşu (IST / SAW / ESB), Türk pasaportu için vize durumunu, TL cinsinden toplam bütçeyi ve gün gün şehir planını gösterir. Uygulama yapay zekâ olmadan tam çalışır; kullanıcı isterse kendi yapay zekâ anahtarını tarayıcıda bağlayıp planı sohbetle değiştirebilir. Tamamen ücretsiz servislerle çalışır ve Vercel'de yayınlanır.

## Komutlar

Node 22 gerekir (`.nvmrc`). Önce `npm ci`.

| Komut | Ne yapar |
| --- | --- |
| `npm run dev` | Geliştirme sunucusu (http://localhost:3000, Turbopack). `VA_AI_MOCK=1 npm run dev` yapay zekâ web aramasını anahtarsız örnek cevaplarla açar |
| `npm run build` | Üretim derlemesi |
| `npm start` | Derlenmiş uygulamayı çalıştırır |
| `npm run lint` | ESLint (uyarı da hata sayılır) |
| `npm run typecheck` | Next.js route tiplerini üretir, ardından `tsc --noEmit` (strict) |
| `npm test` | Vitest + Testing Library, tek seferlik (izleme modu: `npm run test:watch`). `TZ=Asia/Tokyo` ve `VA_TEST_NOW=2026-10-18T00:01:00+03:00` ile başka saat diliminde ve sabit saatte çalıştırılabilir |
| `npm run check:bundle` | Build sonrası: sunucuya özel verinin (mekân dosyaları) ve Travelpayouts token'ının, başlığının ve API adresinin istemci paketine sızmadığını kontrol eder (CI build'i sahte bir token'la yapar) |
| `npm run test:e2e` | Playwright: üretim build'ine karşı uçtan uca testler (önce `npm run build`; ilk seferde `npx playwright install chromium`) |
| `npm run data:places` | 68 şehir için mekân verisini (OSM/Overpass, Wikidata ve Wikidata Query Service, Commons) sırayla çekip `src/data/places/<KOD>.json`'a yazar (ağ ister; ~3 saat). Kaldığı yerden sürer: son 24 saatte bu dosya sürümüyle çekilmiş şehirleri atlar, `-- --force` hepsini yeniden çeker, `-- BCN SJJ` yalnızca o şehirleri. Uygulama bu dosyaları yalnızca sunucuda okur |
| `npm run data:visa` | Vize verisini indirir, yalnızca TR pasaportunu `src/data/visa-tr.json`'a yazar (ağ ister; JSON commit'lenir, build ve CI vize verisi için internete çıkmaz) |
| `npm run verify:partner-links` | Yerelde kurulan Aviasales partner linklerini (`tp.media`, marker + trs) Travelpayouts'un `links/v1/create` API'sinin döndürdüğüyle karşılaştırır (ağ ve `.env.local` ister, CI'da çalışmaz, değerleri yazdırmaz) |
| `npm run data:kinds` | Yalnızca Wikidata'ya sorarak (Overpass yok, birkaç dakika) kayıtlı dosyalardaki tür etiketlerini ve OSM nesnesi ile Wikidata kaydı arasındaki koordinat kontrolünü tazeler; `place-overrides.ts`'teki `relink` kayıtlarını uygular (`-- NYC DUB` yalnızca o şehirler) |
| `npm run verify:place-links` | Gösterilen yerlerin Wikidata bağlantılarını denetler (yanlış bağlantılar, resmî konutlar, karar verilecek hükümet binaları); yalnızca okur, ağ ister, CI'da çalışmaz |
| `npm run verify:destinations` | `src/data/destinations.ts`'i Wikidata'ya karşı yeniden doğrular (ağ ister, CI'da çalışmaz) |

CI (`.github/workflows/ci.yml`) her push ve PR'da iki iş çalıştırır: birim testleri beş saat dilimi/saat birleşiminde (UTC, Asia/Tokyo; Los Angeles, Tokyo ve İstanbul'da sabit İstanbul saati 23:59, 00:01, 03:20) ve `npm ci`, lint, typecheck, build, `check:bundle`, e2e. Playwright tarayıcısı önbelleğe alınır.

## Kod düzeni

- `src/app/globals.css` — tüm renk token'ları (light + dark), Tailwind teması, grain dokusu. Ham renk değeri yalnızca burada durur; `src/test/design-tokens.test.ts` bunu ve WCAG AA kontrastını denetler.
- `src/app/fonts.ts` — Fraunces, Geist, Geist Mono (`next/font/google`).
- `src/components/ui/` — temel bileşenler: Button, Caption, Chip, Skeleton, Stamp, Ticket.
- `src/lib/format.ts` — `tr-TR` biçimlendirme (`12.450 ₺`, `14 Kas Cmt`, 24 saat).
- `src/data/` — kalkış şehirleri (`origins.ts`) ve ~65 varış şehri (`destinations.ts`; QID ve koordinatlar Wikidata'dan).
- `src/lib/search/` — arama durumu: URL ayrıştırma ve doğrulama yalnızca `params.ts`'te (zod); tarih kuralları `dates.ts`; Türkçe arama `normalize.ts`.
- `src/lib/visa/` — vize: CSV → JSON dönüşümü, gereklilik türleri, damga metinleri. `src/lib/rates/` — kur: TCMB → Frankfurter → Exchange Rate API, 4 sn zaman aşımı, ~6 saat önbellek, asla uydurma kur yok.
- `src/lib/flights/` — uçuşlar: Travelpayouts `v3/prices_for_dates` (sorgu `params.ts`, zod şeması `schema.ts`, bilet hesapları `tickets.ts`, linkler `links.ts`). Token yalnızca `client.ts`'te (`server-only`) okunur ve `X-Access-Token` başlığıyla gider; IST ve SAW ayrı sorgulanır, cevaplar birleştirilip her bilet kendi kalkış havalimanına göre gruplanır (IST sorgusu SAW biletleri de döndürür), tam tarihte sonuç yoksa ±3 gün yedeği "FARKLI TARİH" etiketiyle. `VA_FLIGHTS_FIXTURES=1` (Vercel dışında) `__fixtures__/` örnek verisini görünür bir "ÖRNEK VERİ" bandıyla açar.
- `src/lib/budget/` — bütçe fişi: para tam sayı kuruş olarak tutulur, kur çevrimi BigInt ile (`money.ts`, kayan nokta toplamı yok); URL durumu `params.ts` (`flight`, `stay`, `daily`, `cur`); satırlar ve kısmi toplam `receipt.ts`. Konaklama ve günlük harcama için hazır/ortalama değer **konmaz**: yalnızca kullanıcının girdiği değer (8. adımda yapay zekâ tahmini eklenecek). `src/lib/stays/` — Booking ve Google Hotels linkleri (API yok). `src/lib/flights/select.ts` — bütçedeki bilet (`?flight=`, yoksa seçilen tarihlerin en ucuzu).
- `src/lib/itinerary/` — gün gün plan (deterministik; rastgelelik yok, her sıralama tam sıralı; yapay zekâ yalnızca `pinned` ile seçim önerir): tüm süreler ve eşikler `config.ts`'te; `plan.ts` gün pencereleri (uçuşa göre ya da 13:00'te bölünen yarım günler; gündüz 18:00'e kadar zamana göre dolar, en fazla 6 durak; akşam 19:30, geç varışta en geç 21:30; 90 dk'dan uzun boşluk "SERBEST ZAMAN"; uçuş yüzünden durak kalmayan ilk/son günde Uçuşlar'a linkli not), gezinin bütünü için seçim (gündüz kapasitesine göre Vikipedi dil sayısıyla en önemli yerler, müzeler en fazla %40, aynı noktadaki kayıtlar tek ziyaret; önce bunlar kapasiteye duyarlı biçimde bölgelere ve günlere dağıtılır, en bilinen yerin bölgesi ilk uzun günü alır, en önemli 5 yer önce yerleştirilir, boşluklar daha az bilinenlerle, genel adlılar en sona, Wikidata'sız manzara noktası günde en fazla 1; 60+ dilde olan görülecek yer 2 saat), bölgelere ayrılmış çapalar, en yakın komşu sırası, açılış saati kontrolü (`openCheck.ts`); gündüz duraklarında şehir rehberiyle aynı ikiz kuralı (`places/twins.ts`, çıkarılan mekânın ikizi geri gelmez), akşam mekânlarında birleştirme yok ama aynı ad (zincir şubesi) planda yalnızca bir kez önerilir. `ics.ts` RFC 5545 takvim dosyası (TZID + VTIMEZONE, 75 oktet katlama). Çıkarılanlar `?skip=` (kısa OSM kimlikleri, `ids.ts`).
- **Yazdırma:** plan sayfası yalnızca başlık, uçuş özeti, vize, bütçe toplamı ve gün gün planı basar (`print:hidden`, açık palet `globals.css`'te).
- `src/lib/places/` — şehir rehberi: kategori eşlemesi tek dosyada (`categories.ts`), Overpass sorgusu, sıralama (Vikipedi dil sayısı ya da OSM kaydının ayrıntısı; görülecek yer, müze ve manzarada aynı adlı ve 1 km içindeki OSM nesneleri tek mekân sayılır, `twins.ts`; yeme-içmede aynı ad çoğunlukla zincirin başka şubesi olduğu için birleştirilmez), `?cats=` parametresi; veri önceden çekilmiş JSON'dan (`src/data/places/`, ODbL) sunucuda okunur, çalışma anında Overpass/Wikidata/Commons çağrısı yok. **Önemli yerler** Wikidata Query Service'ten de gelir (`landmarks.ts`: şehir yarıçapında, 40+ dilde olanlar 2 katına kadar; Vatikan'dakiler "VATİKAN" etiketiyle) ve OSM'le Wikidata kimliği ya da 150 m içinde benzer adla birleşir. Dosyalar **ham aday** tutar: her yerin bizim kullandığımız Wikidata sınıflarına eşlenmiş türleri (`kinds.ts`; miras tescili `heritage`, UNESCO `unesco`). Neyin görülecek yer sayıldığı **okurken** karar verilir (`rules.ts`, `load.ts`'te rehber ve plan için aynı): gece kulübü ve sinema hiç, tescilsiz konser salonu/müzik mekânı/tiyatro yok (opera binası, UNESCO, müze, kalıntı, kule hariç), istasyon/otel/cadde yalnızca OSM işaretlemişse; cadde, meydan, köprü ve sahil yolu `walkThrough` (planda en fazla 45 dk). **Yanlış bağlantı:** OSM nesnesinin Wikidata kaydı 2 km'den uzaksa, koordinatsız bir olay/kişi/kavramsa, koordinatsız bir kurumsa (OSM müze demiyorsa) ya da bir üniversiteyse dil sayısı önemde kullanılmaz (Sorbonne galerisi, Foucault sarkacı). **Resmî konut ve hükümet merkezi** (Élysée, 10 Downing Street) rehberde kalır, plana girmez; müze olanlar muaf, hükümet binaları ve meclisler kurala girmez. Elle istisnalar `src/data/place-overrides.ts`'te (şehir başına `include` — veride olmayan yer `data:kinds` ile Wikidata'dan eklenir, `remote` "MERKEZE UZAK · TOPLU TAŞIMA ÖNERİLİR" der ve planda kendi bölgesi olur —, `exclude`, `open`, `visit` (yalnızca süre), `exteriorOnly` — en fazla 20 dk, "YALNIZCA DIŞARIDAN", isteğe bağlı `openMonths` ve not — ve `relink`: yanlış bağlı OSM nesnesini doğru kayda taşır, `npm run data:kinds` uygular; her kayıtta QID ve tek satır gerekçe; test, QID veride yoksa ya da relink uygulanmamışsa kırılır). Kural değişikliği yeniden çekme gerektirmez. Görülecek yer ve müze 40, diğerleri 30 gösterilir. Açılış saatleri `hours.ts` (desteklenmeyen biçim gizlenir). `src/lib/city/` — masthead: Commons fotoğrafı ve lisans filtresi, koordinat ve yerel saat.
- Wikimedia/Wikidata/Overpass istekleri (yalnızca veri script'inde) `VacationAssistant/0.1 (https://github.com/Tngc93/vacation-assistant)` User-Agent'ı ile gider. `VA_OFFLINE=1` (yalnızca e2e sunucusu) tüm dış kaynakları anında başarısız kılar.
- `src/lib/ai/` — isteğe bağlı yapay zekâ (PRD 21–26), **deterministik çekirdek karar verir, model önerir ve açıklar**. `providers.ts`: Anthropic, OpenAI ve Gemini'ye tarayıcıdan doğrudan `fetch` (SDK yok; üçü de CORS'a açık; Anthropic için `anthropic-dangerous-direct-browser-access: true`), model adları sağlayıcının model listesinden gelir, hızlı/ucuz olan aile adıyla önerilir (Haiku, `-mini`, Flash). `keyStore.ts`: anahtar yalnızca tarayıcıda (sessionStorage; "Bu cihazda hatırla" ile localStorage), URL'de ve sunucuda asla. `prompts.ts`: modele kısa aday listesi (kısa kimlik, ad, kategori, dil sayısı, koordinat, kapalı olduğu günler) ve gün pencereleri JSON veri olarak gider; adlardaki talimatlar yok sayılır. `assistant.ts`: cevap zod ile doğrulanır, liste dışı kimlik/şema hatası modele gösterilip bir kez daha sorulur, yine olmazsa plan değişmez. `edits.ts`: sohbet düzenlemeleri komuttur (`remove`, `add`, `move`, `pace`, `evening`), motor uygular, her mesaj bir geri alınabilir grup; `?ai=` (günlere seçilen duraklar) ve `?edit=` URL'de durur, paylaşılan link aynı planı açar. `errors.ts`: Türkçe, sakin hata metinleri; HTTP 400 ve diğer 4xx "request" (Gemini'de `API_KEY_INVALID` yine "auth"), "invalid" yalnızca modelin cevabı şemaya/kurallara uymadığında; 503/529 "overloaded" (model yoğun), Gemini 429'unda `QuotaFailure`/`RetryInfo` okunur (`PerDay` → kota, limit 0 → ücretsiz katmanda yok, diğerleri → dakikalık sınır ve bekleme süresi); mesajın altındaki caption yalnızca `HTTP 503 · <model>` (ham hata metni, anahtar, gövde asla). `providers.ts` 500/502/503/504/529 ve ağ hatasında en fazla 2 kez daha dener (~1 sn, ~3 sn, ±%25), 10 sn'den kısa Retry-After/retryDelay'de bir kez bekleyip dener; zaman aşımı tüm denemeleri kapsar ve tekrar denenmez. `mockProvider.ts`: testler için sahte sağlayıcı. Motor (`plan.ts`) `pinned` (verilen sırayla zamanla, başka yer ekleme, sığmayanı `dropped`'a yaz) ve `pace: "relaxed"` (günde en fazla 4 durak) alır. Arayüz `src/components/ai/AiPanel.tsx`. **Web araması** (PRD 8–9): `webSearch.ts` modelin kendi arama aracını tarayıcıdan çağırır (Anthropic `web_search_20250305`, OpenAI Responses `web_search` + `include: ["web_search_call.action.sources"]`, Gemini `generateContent` + `google_search`; JSON modu yok, cevaptaki JSON bloğu zod ile okunur; dokümanlar 2026-10-21'de doğrulandı, ayrıntı dosyanın başında). `webPrices.ts` (Anthropic ve OpenAI): her sonuçta başlık, fiyat, ISO para birimi, baz ve sayfa; sayfa sağlayıcının kendi kaynak listesinde değilse ya da https değilse sonuç atılır, gösterilen link her zaman sağlayıcınınki; TL karşılığı bizim kurumuzla (`src/lib/rates/table.ts`, sunucudan) ve "tahmini", kur yoksa TL yok. `webCache.ts`: aynı arama (rota + tarih + kişi) sekme açıkken sessionStorage'da; "Yeniden ara" yeniler. Uçuşlarda Travelpayouts listesinin altında ayrı "Web'de ara" (`src/components/flights/WebFlightSearch.tsx`, kesik çizgili kart, accent ve "EN UCUZ" yok; "Bütçeye ekle" `?wf=` kişi başı TL ve `?wfs=` site adını yazar, `?flight=`'ı siler), konaklamada semt aralıkları (`src/components/stays/WebStaySearch.tsx`, "Bütçeye yaz" aralığın ortasını bütçenin gecelik alanına `va:budget-stay` olayıyla yazar). **Gemini grounding sonuçları değiştirilmeden gösterilir** ([koşullar](https://ai.google.dev/gemini-api/terms#grounding-with-google-search): değiştirme, karıştırma, önbellek, çerçeve, analiz ve tıklama takibi yok): Gemini düz Türkçe metinle cevaplar (`searchGrounded`), metin olduğu gibi, altında `groundingChunks` linkleri Google'ın verdiği hâliyle ve Search Suggestions (`searchEntryPoint.renderedContent`, shadow root'ta, değiştirilmeden; betik/olay işleyici/https dışı link içerirse eklenmez, sorgular düz metin olur); fiyat okuma, TL, önbellek ve bütçe butonu yok, altında "Fiyatı doğruladıktan sonra bütçeye kendin yazabilirsin." Seçili model ücretsiz katmanda aramıyorsa, anahtarın model listesinde bir Gemini 2.5 Flash varsa o arama onunla yapılabilir (bağlantının modeli değişmez). Anthropic ve OpenAI'da kaynak linki her sonuçta görünür (iki sağlayıcının atıf kuralı). Bütçede web fiyatı (`?wf=`) varken gün gün plan başka biletin saatlerini kullanmaz: varsayılan pencereler ve "UÇUŞ SAATİ BİLİNMİYOR · VARSAYILAN SAATLER". `VA_AI_MOCK=1` (Vercel dışında; e2e'de açık) anahtarsız demo: `mockProvider.ts`'in örnek cevapları (OpenAI biçiminde, yapılandırılmış yol), her sonuçta "ÖRNEK VERİ".
- **Content-Security-Policy** (`src/lib/security/csp.ts`, `next.config.ts` her sayfaya ekler): `connect-src` yalnızca kendi alanımız, `tiles.openfreemap.org` (harita) ve üç sağlayıcının API alanı (`src/lib/ai/origins.ts`).
- `src/components/search/` — biniş kartı arama formu: kalkış, combobox, tarih aralığı, yolcu.
- `/` arama formu · `/plan?from=IST&to=BCN&depart=2026-11-14&return=2026-11-18&pax=2` plan sayfası · `/styleguide` bileşen vitrini.

## Çalışma kuralları

- **Branch ve PR:** Her iş PLAN.md'deki gibi kendi branch'inde yapılır (`feat/…`, `fix/…`, `chore/…`). `main`'e doğrudan commit ya da push yok. PR açmadan önce Berk'e sorulur.
- **Tamamen ücretsiz:** Ücretli servis, kredi kartı isteyen API ya da ücretli paket yok. Emin değilsen sor.
- **Kazıma yok:** Uçuş, otel ya da arama sitelerini kazıma (scraping) yok. Veri yalnızca PRD'deki kaynaklardan gelir.
- **Gizli anahtarlar:** Yalnızca `.env.local`'de ve Vercel ortam değişkenlerinde durur. Asla commit'lenmez, asla istemciye gitmez. `.env.example`'da yalnızca değişken adları olur.
- **Kullanıcının yapay zekâ anahtarı:** Yalnızca tarayıcıda tutulur, sunucuya kaydedilmez ve loglanmaz.
- **Dürüst veri:** Her fiyat ve tahmin kaynağını ve "tahmini" etiketini gösterir. Uydurma veri yok. Bir kaynak cevap vermezse bunu açıkça göster.
- **Dil:** Arayüz metinleri Türkçe; kod, yorumlar ve commit mesajları İngilizce.
- **Tasarım:** Görsel kararlar DESIGN.md'ye uyar. Ham hex renk yok, yalnızca token'lar.
- **Zaman:** Zamana bağlı her fonksiyon `now` parametresi alır; istemci bileşenleri zamanı `useMinuteNow()`'dan okur. Testler sabit saatle çalışır (`vi.setSystemTime` / `vi.useFakeTimers`); gerçek saate, makinenin saat dilimine ya da animasyon karesine bağlı test yok. Zaman aşımları `timeoutSignal` ile kurulur ki sahte saatle sınansın.
- **Kalite kapısı:** Bir adımı bitirmeden önce lint, typecheck ve test geçmeli.
